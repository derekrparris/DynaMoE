High-Performance MoE Inference Engine for Apple Silicon

What's New in 26.0

JetSpec speculative decoding

Speculative tree decoding verified in a single Metal pass, with KV-cache compaction and MoE expert-budget pruning. Enable via dynamoe_jetspec_enabled.

FP8 KV cache

New E4M3 / E5M2 cache precision unlocks long-context sessions on 16 GB machines. Configure under Settings → dynamoe_kv_cache_precision.

Fixes

  • Tool calls: StreamingToolParser no longer freezes generation before the closing tag is emitted.
  • Prefix cache: delta prefill now attends over preserved prefix slots reliably.
  • Memory: telemetry separates dirty heap from clean zero-copy pages again.
