### 📦 What's New in 26.7
* **External tool servers (MCP):** The agent can now use tools that ship as separate programs or remote services instead of Swift compiled into the app. Servers are declared in one editable `mcp.json` (stdio child processes or Streamable HTTP endpoints) and speak the Model Context Protocol, surfacing as ordinary agent tools under `mcp__<server>__<tool>`. A new Settings card shows live status and handles add, edit, enable, restart, and remove, with both a form and a raw JSON editor. The file stays the source of truth (external edits are picked up without a restart, and deferred while a turn is running), credentials live in the Keychain behind `${keychain:...}` tokens so they never touch disk, discovered tools cost zero prefill tokens until the model loads them, and every MCP call asks for approval unless Turbo Mode is on.
* **Corrected KV capacity rules:** A tools-enabled turn is no longer refused before prefill just because the machine cannot afford the 8,192-row agent reserve. The pre-launch check now prices the model's real sliding-window ring layout and the effective KV precision the allocator uses, treats the agent reserve as a preference the RAM budget caps rather than a veto, and refuses a turn only when the prompt itself cannot fit, so a few-thousand-token prompt runs again on a memory-constrained Mac. Rejections say what actually binds (budget, model footprint, precision, affordable rows) and reach API clients as a `context_length_exceeded` error; the new `dynamoe_agent_session_floor` key lowers the reserve when you need to.
* **Connected cloud providers (Synthetic):** Cloud inference becomes a third backend beside local weights and the Apple on-device model. Synthetic's models appear under **Cloud Models** in the composer, and a turn runs against the provider's OpenAI-compatible API with no engine, tokenizer, Metal buffers, or KV cache in the path. With Agent Tools on it uses the provider's native function calling, so streamed tool calls execute through the same harness as a local turn (approvals, Turbo Mode, loop guards, and the subagent report relay). **Test & Sync Models** validates the key and registers the provider's live chat models in one press, keys stay in the login Keychain, and switching to a cloud model releases any resident weights engine.
* **Selectable thinking levels:** Spark X2.6 adds a graded reasoning template, so the Thinking menu offers **High**, **Low**, and **Off** instead of a plain on/off switch for level-capable checkpoints. The choice is stored per conversation and rendered as `reasoning_effort` in both the in-app and API prompts; the OpenAI endpoint takes `"reasoning_effort": "low" | "high"`, the Anthropic endpoint maps `thinking.budget_tokens`, and unsupported values are rejected with `400` instead of being silently ignored.
* **Transcript performance:** Long conversations render without stalling. Display cleanup, markdown parsing, and syntax highlighting are memoized per frame, follow-scroll is throttled to line-sized buckets, and very long paragraphs, quotes, reasoning, and code are drawn as bounded chunks so an oversized text view can no longer leave the transcript blank. The output-token and agent-step ceilings now match what the KV cache can actually provision.

### 🐛 Fixes
* **MCP reliability:** A dead HTTP endpoint no longer keeps a Ready row with tools registered against a corpse, a server that cannot start stays Failed with its error until you retry it or change its config instead of relaunching in a loop, in-place rewrites of `mcp.json` are noticed rather than only atomic saves, a tool-list refresh keeps already-loaded tools loaded, and an external config edit waits for a pending approval or running tool call before it reconnects.
* **MCP wire protocol:** Oversized frames are refused even when they arrive newline-terminated, line scanning stays linear when bytes dribble in one at a time (a large frame could previously stall until timeout), the assembled event is bounded rather than each line alone, JSON-RPC request ids are echoed verbatim (string and zero-padded ids included), an abandoned request notifies the server so state-changing calls stop running remotely, and the protocol revision a server negotiated is used for every later request. Out-of-range timeouts are rejected at validation instead of trapping on connect, arguments round-trip as a JSON array, and credentials are written only after the form validates and rolled back if it does not.
* **Cloud turns:** A cloud turn never registered its own conversation with the agent harness, so a subagent it spawned could surface in the wrong transcript or never surface at all; cloud turns now claim their session and wait for in-flight subagents before relaying. Parallel tool calls that arrive without a stream index are no longer merged into one, a reply cut off by the output-token limit says so in the transcript, abandoned provider responses release their connection instead of lingering, and model rescans no longer probe the Keychain on the main thread.
* **Live speed:** A cloud turn read zero tokens per second while it was thinking and stayed diluted afterwards because only visible content was counted; reasoning and content are now counted together, and a provider-reported total still wins so the header speed matches the final footer number.
* **Markdown and presets:** Oversized paragraphs and quotes keep their bold, code, and link formatting instead of showing literal markers, and duplicate output-token presets are deduplicated so a constant colliding with a literal can no longer crash the settings pane.
* **Settings window:** On macOS 26 the unified toolbar's glass strip covered the top of the detail pane and clipped section headers as they scrolled; the pane now runs full height under a transparent titlebar, so content passes beneath the floating controls instead of disappearing.
* **Under the hood:** Spark X2.6 joins X2.5 in supported models, and the README and settings guide document MCP servers, cloud providers, and the corrected KV capacity rules.
